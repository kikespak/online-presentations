How it was done

Taken apart, not traced

The original file is true vector, so nothing had to be redrawn or auto-traced. The mark comes apart into the badge and every letter as its own shape, which is what lets each one move on its own timing.

1
The badge

The blue field behind everything. It arrives first and carries the weight of the entrance.

15
The letters

B L U E, C O U C H, and L I V E !, each a separate shape with its own delay. That stagger is the whole difference between a logo that animates and a logo that just fades.

Practical

Putting it to work

Format
One self-contained .svg per option, 12 to 14 KB.
Scales to any size without losing an edge.
Embedding
Paste the file into the page, or load it with <object>.
A plain <img> tag freezes it on the first frame in Chrome, which is invisible.
Accessibility
Honours the system setting for reduced motion.
Anyone who has asked for less movement sees the finished logo, still.
Print and static
The last frame is the logo exactly as it is today.
Nothing has been redrawn, so the static mark is unchanged.
